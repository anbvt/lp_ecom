# Laptop E-Commerce Website

A laptop e-commerce web application built with React and TypeScript, integrated with a separate backend API.

### Tech Stack
- **Frontend:** React, TypeScript, Redux
- **Routing & API:** React Router, Axios
- **UI:** Ant Design, Bootstrap
- **Deployment:** Vercel

### Related Repositories
- **Frontend:** [lp_ecom_fe](https://github.com/anbvt/lp_ecom_fe)
- **Backend:** [lp_ecom_be](https://github.com/anbvt/lp_ecom_be)
