# ノートパソコンECサイト

ReactとTypeScriptを使用して開発した、ノートパソコンのECサイトです。フロントエンドとバックエンドを分離した構成を採用し、APIを通じてデータを連携しています。

## 使用技術
- **フロントエンド：** React、TypeScript、Redux
- **ルーティング・API連携：** React Router、Axios
- **UI：** Ant Design、Bootstrap
- **デプロイ：** Vercel

## 関連リポジトリ

- **バックエンド：** [lp_ecom_be](https://github.com/anbvt/lp_ecom_be)
